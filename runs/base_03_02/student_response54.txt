To find the smallest possible value of the expression \(\frac{(a+b)^2+(b-c)^2+(c-a)^2}{b^2}\), we start by expanding the numerator:

\[
(a+b)^2 + (b-c)^2 + (c-a)^2 = a^2 + 2ab + b^2 + b^2 - 2bc + c^2 + c^2 - 2ac + a^2 = 2a^2 + 2b^2 + 2c^2 + 2ab - 2ac - 2bc
\]

We can factor out the 2 from the expression:

\[
2a^2 + 2b^2 + 2c^2 + 2ab - 2ac - 2bc = 2(a^2 + b^2 + c^2 + ab - ac - bc)
\]

Thus, the original expression becomes:

\[
\frac{2(a^2 + b^2 + c^2 + ab - ac - bc)}{b^2} = 2 \left( \frac{a^2 + b^2 + c^2 + ab - ac - bc}{b^2} \right)
\]

We can rewrite the expression inside the parentheses as:

\[
\frac{a^2 + b^2 + c^2 + ab - ac - bc}{b^2} = \frac{a^2}{b^2} + 1 + \frac{c^2}{b^2} + \frac{ab}{b^2} - \frac{ac}{b^2} - \frac{bc}{b^2} = \left( \frac{a}{b} \right)^2 + 1 + \left( \frac{c}{b} \right)^2 + \frac{a}{b} - \frac{a c}{b^2} - \frac{c}{b}
\]

Let's set \(x = \frac{a}{b}\) and \(y = \frac{c}{b}\). Since \(b > c > a\), we have \(0 < x < y < 1\). The expression then becomes:

\[
x^2 + 1 + y^2 + x - xy - y
\]

We need to find the minimum value of this expression. Consider the function \(f(x, y) = x^2 + y^2 + x - xy - y + 1\). To find the critical points, we take the partial derivatives and set them to zero:

\[
\frac{\partial f}{\partial x} = 2x + 1 - y = 0 \implies y = 2x + 1
\]
\[
\frac{\partial f}{\partial y} = 2y - x - 1 = 0 \implies x = 2y - 1
\]

Substituting \(y = 2x + 1\) into \(x = 2y - 1\):

\[
x = 2(2x + 1) - 1 = 4x + 2 - 1 = 4x + 1 \implies x - 4x = 1 \implies -3x = 1 \implies x = -\frac{1}{3}
\]

However, since \(0 < x < 1\), \(x = -\frac{1}{3}\) is not in the valid range. Instead, we can test the boundary values or specific values within the range. Let's test \(x = 0\) and \(y = 0\):

If \(x = 0\) and \(y = 0\):

\[
f(0, 0) = 0^2 + 0^2 + 0 - 0 \cdot 0 - 0 + 1 = 1
\]

We need to check if this is the minimum. Consider the function \(g(x) = x^2 + 1 + y^2 + x - xy - y\) for a fixed \(y\):

\[
g(x) = x^2 + x + 1 + y^2 - xy - y
\]

The derivative is:

\[
g'(x) = 2x + 1 - y
\]

Setting \(g'(x) = 0\):

\[
2x + 1 - y = 0 \implies x = \frac{y - 1}{2}
\]

Since \(0 < y < 1\), \(x = \frac{y - 1}{2} < 0\), which is not in the valid range. Therefore, the minimum value occurs at the boundary, and we have already found that the minimum value is 1 when \(x = 0\) and \(y = 0\).

Thus, the smallest possible value of the expression is:

\[
\boxed{1}
\]
