To find the sum \(\sum_{n=1}^\infty \frac{a_n}{4^{n+1}}\), we start by defining the sum as \(S\):
\[
S = \sum_{n=1}^\infty \frac{a_n}{4^{n+1}}.
\]
We can rewrite the sum by shifting the index:
\[
S = \frac{a_1}{4^2} + \frac{a_2}{4^3} + \frac{a_3}{4^4} + \frac{a_4}{4^5} + \cdots.
\]
Using the recurrence relation \(a_{n+2} = a_{n+1} + a_n\), we can express the sum in terms of itself. First, we write out the series and then use the recurrence relation to find a relationship:
\[
4S = \frac{a_1}{4} + \frac{a_2}{4^2} + \frac{a_3}{4^3} + \frac{a_4}{4^4} + \cdots,
\]
\[
16S = a_1 + \frac{a_2}{4} + \frac{a_3}{4^2} + \frac{a_4}{4^3} + \cdots.
\]
Next, we subtract \(4S\) from \(16S\):
\[
16S - 4S = a_1 + \left(\frac{a_2}{4} - \frac{a_1}{4}\right) + \left(\frac{a_3}{4^2} - \frac{a_2}{4^2} - \frac{a_1}{4^2}\right) + \left(\frac{a_4}{4^3} - \frac{a_3}{4^3} - \frac{a_2}{4^3}\right) + \cdots.
\]
Simplifying the right-hand side, we get:
\[
12S = 1 + \left(\frac{1}{4} - \frac{1}{4}\right) + \left(\frac{1 + 1}{4^2} - \frac{1}{4^2} - \frac{1}{4^2}\right) + \left(\frac{1 + 1 + 1}{4^3} - \frac{1 + 1}{4^3} - \frac{1}{4^3}\right) + \cdots = 1.
\]
So, we have:
\[
12S = 1 \implies S = \frac{1}{12}.
\]
Thus, the sum is:
\[
\boxed{\frac{1}{12}}.
\]
