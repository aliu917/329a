To solve the given equation \(\frac{ \left( \frac{1}{2} \right)^2 + \left( \frac{1}{3} \right)^2 }{ \left( \frac{1}{4} \right)^2 + \left( \frac{1}{5} \right)^2} = \frac{13x}{41y} \), we will first simplify the left-hand side of the equation.

1. Calculate \(\left( \frac{1}{2} \right)^2\) and \(\left( \frac{1}{3} \right)^2\):
   \[
   \left( \frac{1}{2} \right)^2 = \frac{1}{4}, \quad \left( \frac{1}{3} \right)^2 = \frac{1}{9}
   \]
   So, the numerator becomes:
   \[
   \frac{1}{4} + \frac{1}{9} = \frac{9}{36} + \frac{4}{36} = \frac{13}{36}
   \]

2. Calculate \(\left( \frac{1}{4} \right)^2\) and \(\left( \frac{1}{5} \right)^2\):
   \[
   \left( \frac{1}{4} \right)^2 = \frac{1}{16}, \quad \left( \frac{1}{5} \right)^2 = \frac{1}{25}
   \]
   So, the denominator becomes:
   \[
   \frac{1}{16} + \frac{1}{25} = \frac{25}{400} + \frac{16}{400} = \frac{41}{400}
   \]

3. Now, substitute these results back into the original equation:
   \[
   \frac{ \frac{13}{36} }{ \frac{41}{400} } = \frac{13x}{41y}
   \]
   Simplify the left-hand side by multiplying by the reciprocal of the denominator:
   \[
   \frac{13}{36} \times \frac{400}{41} = \frac{13 \times 400}{36 \times 41} = \frac{5200}{1476} = \frac{1300}{369}
   \]
   Therefore, we have:
   \[
   \frac{1300}{369} = \frac{13x}{41y}
   \]
   By comparing the numerators and denominators, we get:
   \[
   1300 = 13x \quad \text{and} \quad 369 = 41y
   \]
   Solving for \(x\) and \(y\):
   \[
   x = \frac{1300}{13} = 100, \quad y = \frac{369}{41} = 9
   \]

4. We need to find \(\sqrt{x} \div \sqrt{y} = \frac{\sqrt{x}}{\sqrt{y}} = \sqrt{\frac{x}{y}}\):
   \[
   \sqrt{\frac{x}{y}} = \sqrt{\frac{100}{9}} = \frac{\sqrt{100}}{\sqrt{9}} = \frac{10}{3}
   \]

The final answer is:
\[
\boxed{\frac{10}{3}}
\]
