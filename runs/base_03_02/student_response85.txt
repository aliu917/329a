To solve for \(\sin(2 \angle BPC)\), we start by placing the points \(A, B, C, D\) on the x-axis with coordinates \(A = 0\), \(B = 1\), \(C = 2\), and \(D = 3\). Let the coordinates of point \(P\) be \((x, y)\).

First, we use the cosine rule in triangles \(APC\) and \(BPD\). The cosine rule states that for a triangle with sides \(a\), \(b\), and \(c\) opposite angles \(A\), \(B\), and \(C\) respectively, \(\cos C = \frac{a^2 + b^2 - c^2}{2ab}\).

For \(\triangle APC\), the sides are \(AP = \sqrt{x^2 + y^2}\), \(PC = \sqrt{(x-2)^2 + y^2}\), and \(AC = 2\). Using the cosine rule, we get:
\[
\cos \angle APC = \frac{AP^2 + PC^2 - AC^2}{2 \cdot AP \cdot PC} = \frac{x^2 + y^2 + (x-2)^2 + y^2 - 4}{2 \sqrt{x^2 + y^2} \sqrt{(x-2)^2 + y^2}} = \frac{2x^2 - 4x + 2y^2 - 4}{2 \sqrt{x^2 + y^2} \sqrt{(x-2)^2 + y^2}} = \frac{x^2 - 2x + y^2 - 2}{\sqrt{x^2 + y^2} \sqrt{(x-2)^2 + y^2}}.
\]
Given \(\cos \angle APC = \frac{4}{5}\), we have:
\[
\frac{x^2 - 2x + y^2 - 2}{\sqrt{x^2 + y^2} \sqrt{(x-2)^2 + y^2}} = \frac{4}{5}.
\]

For \(\triangle BPD\), the sides are \(BP = \sqrt{(x-1)^2 + y^2}\), \(PD = \sqrt{(x-3)^2 + y^2}\), and \(BD = 2\). Using the cosine rule, we get:
\[
\cos \angle BPD = \frac{BP^2 + PD^2 - BD^2}{2 \cdot BP \cdot PD} = \frac{(x-1)^2 + y^2 + (x-3)^2 + y^2 - 4}{2 \sqrt{(x-1)^2 + y^2} \sqrt{(x-3)^2 + y^2}} = \frac{2x^2 - 8x + 10 + 2y^2 - 4}{2 \sqrt{(x-1)^2 + y^2} \sqrt{(x-3)^2 + y^2}} = \frac{x^2 - 4x + y^2 + 3}{\sqrt{(x-1)^2 + y^2} \sqrt{(x-3)^2 + y^2}}.
\]
Given \(\cos \angle BPD = \frac{3}{5}\), we have:
\[
\frac{x^2 - 4x + y^2 + 3}{\sqrt{(x-1)^2 + y^2} \sqrt{(x-3)^2 + y^2}} = \frac{3}{5}.
\]

To find \(\sin(2 \angle BPC)\), we use the double angle formula \(\sin(2\theta) = 2 \sin \theta \cos \theta\). We need to find \(\sin \angle BPC\) and \(\cos \angle BPC\). Let \(\angle BPC = \theta\). Then, using the cosine rule in \(\triangle BPC\), we get:
\[
\cos \theta = \frac{BC^2 + PC^2 - BP^2}{2 \cdot BC \cdot PC} = \frac{1 + (x-2)^2 + y^2 - (x-1)^2 - y^2}{2 \cdot 1 \cdot \sqrt{(x-2)^2 + y^2}} = \frac{1 + x^2 - 4x + 4 - x^2 + 2x - 1}{2 \sqrt{(x-2)^2 + y^2}} = \frac{-2x + 4}{2 \sqrt{(x-2)^2 + y^2}} = \frac{-x + 2}{\sqrt{(x-2)^2 + y^2}}.
\]
Given \(\cos \angle APC = \frac{4}{5}\) and \(\cos \angle BPD = \frac{3}{5}\), we can use the fact that \(\angle BPC = \angle APC - \angle BPD\). Using the cosine subtraction formula, we get:
\[
\cos \theta = \cos \angle APC \cos \angle BPD + \sin \angle APC \sin \angle BPD = \frac{4}{5} \cdot \frac{3}{5} + \sqrt{1 - \left(\frac{4}{5}\right)^2} \cdot \sqrt{1 - \left(\frac{3}{5}\right)^2} = \frac{12}{25} + \frac{3}{5} \cdot \frac{4}{5} = \frac{12}{25} + \frac{12}{25} = \frac{24}{25}.
\]
Then, \(\sin \theta = \sqrt{1 - \left(\frac{24}{25}\right)^2} = \sqrt{\frac{49}{625}} = \frac{7}{25}\). Therefore,
\[
\sin(2\theta) = 2 \sin \theta \cos \theta = 2 \cdot \frac{7}{25} \cdot \frac{24}{25} = \frac{336}{625}.
\]
Thus, the answer is:
\[
\boxed{\frac{336}{625}}.
