Given that \(a, b, c\) form a geometric sequence, we can express \(b\) and \(c\) in terms of \(a\) and a common ratio \(r\). Specifically, we have \(b = ar\) and \(c = ar^2\).

We are also given that \(\log_c a, \ \log_b c, \ \log_a b\) form an arithmetic sequence. Let's denote the common difference of this arithmetic sequence by \(d\). Therefore, we have:
\[
\log_b c - \log_c a = \log_a b - \log_b c
\]
This can be rewritten as:
\[
2 \log_b c = \log_c a + \log_a b
\]

First, we express each logarithm in terms of base 10 logarithms:
\[
\log_b c = \frac{\log c}{\log b} = \frac{\log (ar^2)}{\log (ar)} = \frac{\log a + \log r^2}{\log a + \log r} = \frac{\log a + 2 \log r}{\log a + \log r}
\]
\[
\log_c a = \frac{\log a}{\log c} = \frac{\log a}{\log (ar^2)} = \frac{\log a}{\log a + 2 \log r}
\]
\[
\log_a b = \frac{\log b}{\log a} = \frac{\log (ar)}{\log a} = \frac{\log a + \log r}{\log a} = 1 + \frac{\log r}{\log a}
\]

Now, substitute these expressions into the equation \(2 \log_b c = \log_c a + \log_a b\):
\[
2 \cdot \frac{\log a + 2 \log r}{\log a + \log r} = \frac{\log a}{\log a + 2 \log r} + 1 + \frac{\log r}{\log a}
\]

To simplify, let \(x = \log a\) and \(y = \log r\). The equation becomes:
\[
2 \cdot \frac{x + 2y}{x + y} = \frac{x}{x + 2y} + 1 + \frac{y}{x}
\]

Multiply through by \((x + y)(x + 2y) x\) to clear the denominators:
\[
2x(x + y)(x + 2y) = x(x + y) + (x + y)(x + 2y) x + y(x + y)(x + 2y)
\]
\[
2x(x^2 + 3xy + 2y^2) = x^2(x + y) + x(x + 2y)(x + y) + y(x + y)(x + 2y)
\]
\[
2x^3 + 6x^2 y + 4xy^2 = x^3 + x^2 y + x^3 + 3x^2 y + 2xy^2 + x^2 y + 2xy^2 + y^2 x + 2y^3
\]
\[
2x^3 + 6x^2 y + 4xy^2 = 2x^3 + 5x^2 y + 5xy^2 + y^2 x + 2y^3
\]
\[
0 = 5x^2 y + 5xy^2 + y^2 x + 2y^3 - 6x^2 y - 4xy^2
\]
\[
0 = -x^2 y + xy^2 + y^2 x + 2y^3 - 4xy^2
\]
\[
0 = -x^2 y + y^2 x + 2y^3 - 3xy^2
\]
\[
0 = y(-x^2 + xy + 2y^2 - 3xy)
\]
\[
0 = y(-x^2 - 2xy + 2y^2)
\]

Since \(y \neq 0\) (because \(r \neq 1\)), we have:
\[
0 = -x^2 - 2xy + 2y^2
\]
\[
x^2 + 2xy - 2y^2 = 0
\]

Solving this quadratic equation in \(x\):
\[
x = \frac{-2y \pm \sqrt{(2y)^2 - 4 \cdot 1 \cdot (-2y^2)}}{2 \cdot 1} = \frac{-2y \pm \sqrt{4y^2 + 8y^2}}{2} = \frac{-2y \pm \sqrt{12y^2}}{2} = \frac{-2y \pm 2y\sqrt{3}}{2} = -y \pm y\sqrt{3}
\]

Thus, \(x = (-1 + \sqrt{3})y\) or \(x = (-1 - \sqrt{3})y\). Since \(a, b, c\) are positive real numbers, we take the positive root:
\[
x = (\sqrt{3} - 1)y
\]

Now, we find \(\log_b c\):
\[
\log_b c = \frac{\log a + 2 \log r}{\log a + \log r} = \frac{x + 2y}{x + y} = \frac{(\sqrt{3} - 1)y + 2y}{(\sqrt{3} - 1)y + y} = \frac{(\sqrt{3} + 1)y}{\sqrt{3} y} = \frac{\sqrt{3} + 1}{\sqrt{3}} = 1 + \frac{1}{\sqrt{3}} = 1 + \frac{\sqrt{3}}{3}
\]

The common difference \(d\) of the arithmetic sequence is:
\[
d = \log_b c - \log_c a = \left(1 + \frac{\sqrt{3}}{3}\right) - \left(\frac{1}{\sqrt{3}}\right) = 1 + \frac{\sqrt{3}}{3} - \frac{\sqrt{3}}{3} = 1
\]

Thus, the common difference is \(\boxed{1}\).
