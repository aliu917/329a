To solve the equation \(\tan \theta + \tan 2\theta + \tan 3\theta = 0\) for \(\theta\) in the range \(0^\circ < \theta < 45^\circ\), we will use trigonometric identities and properties of the tangent function.

First, recall the double-angle and triple-angle formulas for tangent:
\[
\tan 2\theta = \frac{2\tan \theta}{1 - \tan^2 \theta}
\]
\[
\tan 3\theta = \frac{3\tan \theta - \tan^3 \theta}{1 - 3\tan^2 \theta}
\]

Let \(t = \tan \theta\). Then the equation becomes:
\[
t + \frac{2t}{1 - t^2} + \frac{3t - t^3}{1 - 3t^2} = 0
\]

To combine these terms, we need a common denominator. The common denominator for the three terms is \((1 - t^2)(1 - 3t^2)\). Rewriting each term with this common denominator, we get:
\[
t \cdot \frac{(1 - 3t^2)(1 - t^2)}{(1 - t^2)(1 - 3t^2)} + \frac{2t(1 - 3t^2)}{(1 - t^2)(1 - 3t^2)} + \frac{(3t - t^3)(1 - t^2)}{(1 - t^2)(1 - 3t^2)} = 0
\]

Simplifying the numerators, we have:
\[
\frac{t(1 - 3t^2)(1 - t^2) + 2t(1 - 3t^2) + (3t - t^3)(1 - t^2)}{(1 - t^2)(1 - 3t^2)} = 0
\]

The numerator must be zero:
\[
t(1 - 3t^2)(1 - t^2) + 2t(1 - 3t^2) + (3t - t^3)(1 - t^2) = 0
\]

Expanding each term:
\[
t(1 - 3t^2 - t^2 + 3t^4) + 2t(1 - 3t^2) + (3t - 3t^3 - t^3 + t^5) = 0
\]
\[
t(1 - 4t^2 + 3t^4) + 2t(1 - 3t^2) + (3t - 4t^3 + t^5) = 0
\]
\[
t - 4t^3 + 3t^5 + 2t - 6t^3 + 3t - 4t^3 + t^5 = 0
\]
\[
6t - 14t^3 + 4t^5 = 0
\]

Factoring out \(2t\):
\[
2t(3 - 7t^2 + 2t^4) = 0
\]

Since \(t \neq 0\) in the given range, we solve:
\[
3 - 7t^2 + 2t^4 = 0
\]

Let \(x = t^2\). Then the equation becomes:
\[
2x^2 - 7x + 3 = 0
\]

Solving this quadratic equation using the quadratic formula \(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\):
\[
x = \frac{7 \pm \sqrt{49 - 24}}{4} = \frac{7 \pm \sqrt{25}}{4} = \frac{7 \pm 5}{4}
\]

Thus, we have two solutions:
\[
x = \frac{12}{4} = 3 \quad \text{and} \quad x = \frac{2}{4} = \frac{1}{2}
\]

Since \(x = t^2\) and \(0 < \theta < 45^\circ\), \(t\) must be positive and less than 1. Therefore, we discard \(x = 3\) and keep:
\[
t^2 = \frac{1}{2}
\]
\[
t = \sqrt{\frac{1}{2}} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}
\]

Thus, the value of \(\tan \theta\) is:
\[
\boxed{\frac{\sqrt{2}}{2}}
\]
