To find the maximum value of the expression \((x^2 - xy + y^2)(x^2 - xz + z^2)(y^2 - yz + z^2)\) given that \(x + y + z = 2\) and \(x, y, z \geq 0\), we will analyze the expression step by step.

First, observe that the expression \(x^2 - xy + y^2\) is always nonnegative because it can be rewritten as \(\frac{1}{2}((x-y)^2 + x^2 + y^2) \geq 0\). Similarly, \(x^2 - xz + z^2 \geq 0\) and \(y^2 - yz + z^2 \geq 0\).

Let's consider some specific cases to find the maximum value.

**Case 1: \(x = 2, y = 0, z = 0\)**

\[
(x^2 - xy + y^2)(x^2 - xz + z^2)(y^2 - yz + z^2) = (2^2 - 2 \cdot 0 + 0^2)(2^2 - 2 \cdot 0 + 0^2)(0^2 - 0 \cdot 0 + 0^2) = 4 \cdot 4 \cdot 0 = 0.
\]

**Case 2: \(x = 1, y = 1, z = 0\)**

\[
(x^2 - xy + y^2)(x^2 - xz + z^2)(y^2 - yz + z^2) = (1^2 - 1 \cdot 1 + 1^2)(1^2 - 1 \cdot 0 + 0^2)(1^2 - 1 \cdot 0 + 0^2) = (1 - 1 + 1)(1)(1) = 1.
\]

**Case 3: \(x = 1, y = 0, z = 1\)**

\[
(x^2 - xy + y^2)(x^2 - xz + z^2)(y^2 - yz + z^2) = (1^2 - 1 \cdot 0 + 0^2)(1^2 - 1 \cdot 1 + 1^2)(0^2 - 0 \cdot 1 + 1^2) = (1)(1 - 1 + 1)(1) = 1.
\]

**Case 4: \(x = 0, y = 1, z = 1\)**

\[
(x^2 - xy + y^2)(x^2 - xz + z^2)(y^2 - yz + z^2) = (0^2 - 0 \cdot 1 + 1^2)(0^2 - 0 \cdot 1 + 1^2)(1^2 - 1 \cdot 1 + 1^2) = (1)(1)(1 - 1 + 1) = 1.
\]

**Case 5: \(x = \frac{2}{3}, y = \frac{2}{3}, z = \frac{2}{3}\)**

\[
(x^2 - xy + y^2)(x^2 - xz + z^2)(y^2 - yz + z^2) = \left(\left(\frac{2}{3}\right)^2 - \left(\frac{2}{3}\right)\left(\frac{2}{3}\right) + \left(\frac{2}{3}\right)^2\right)^3 = \left(\frac{4}{9} - \frac{4}{9} + \frac{4}{9}\right)^3 = \left(\frac{4}{9}\right)^3 = \frac{64}{729}.
\]

From the above cases, the maximum value of the expression is 1, which is achieved in the cases where two of the variables are 1 and the other is 0. Therefore, the maximum value is \(\boxed{1}\).
