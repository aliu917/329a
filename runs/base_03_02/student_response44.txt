To determine the number of connections necessary in the network where each of the 20 switches is directly connected to exactly 3 other switches, we can follow these steps:

1. **Calculate the total number of connections if we count from each switch's perspective:**
   Each switch is connected to 3 other switches. Therefore, if we count the connections from the perspective of all 20 switches, we would count \(20 \times 3 = 60\) connections. However, this count includes each connection twice (once for each switch it connects), so we need to divide by 2 to get the actual number of unique connections.

2. **Divide by 2 to get the actual number of connections:**
   The actual number of connections is \(\frac{60}{2} = 30\).

So, the number of connections necessary is \(\boxed{30}\).
