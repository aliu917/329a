To solve the inequality \(\frac{1}{x - 1} - \frac{4}{x - 2} + \frac{4}{x - 3} - \frac{1}{x - 4} < \frac{1}{30}\), we first analyze the behavior of the function at the points where it is undefined, which are \(x = 1, 2, 3, 4\). These points will help us determine the intervals to test.

### Step 1: Identify the critical points
The function is undefined at \(x = 1, 2, 3, 4\). We need to test the intervals \((-\infty, 1)\), \((1, 2)\), \((2, 3)\), \((3, 4)\), and \((4, \infty)\).

### Step 2: Simplify the expression
We can try to simplify the left side of the inequality, but it is often more effective to analyze the behavior around the critical points directly.

### Step 3: Analyze the behavior around each critical point
#### Interval \((-\infty, 1)\)
Choose \(x = 0\):
\[
\frac{1}{0 - 1} - \frac{4}{0 - 2} + \frac{4}{0 - 3} - \frac{1}{0 - 4} = -1 + 2 - \frac{4}{3} + \frac{1}{4} = -1 + 2 - 1.333 + 0.25 = -0.083 < \frac{1}{30} \approx 0.033
\]
So, the inequality holds in \((-\infty, 1)\).

#### Interval \((1, 2)\)
Choose \(x = 1.5\):
\[
\frac{1}{1.5 - 1} - \frac{4}{1.5 - 2} + \frac{4}{1.5 - 3} - \frac{1}{1.5 - 4} = 2 + 8 - \frac{4}{1.5} + \frac{1}{2.5} = 2 + 8 - 2.667 + 0.4 = 7.733 > \frac{1}{30} \approx 0.033
\]
So, the inequality does not hold in \((1, 2)\).

#### Interval \((2, 3)\)
Choose \(x = 2.5\):
\[
\frac{1}{2.5 - 1} - \frac{4}{2.5 - 2} + \frac{4}{2.5 - 3} - \frac{1}{2.5 - 4} = \frac{1}{1.5} - 8 - \frac{4}{0.5} + \frac{1}{1.5} = \frac{2}{3} - 8 - 8 + \frac{2}{3} = \frac{4}{3} - 16 = -14.667 < \frac{1}{30} \approx 0.033
\]
So, the inequality holds in \((2, 3)\).

#### Interval \((3, 4)\)
Choose \(x = 3.5\):
\[
\frac{1}{3.5 - 1} - \frac{4}{3.5 - 2} + \frac{4}{3.5 - 3} - \frac{1}{3.5 - 4} = \frac{1}{2.5} - \frac{4}{1.5} + 4 + 2 = \frac{2}{5} - \frac{8}{3} + 4 + 2 = 0.4 - 2.667 + 6 = 3.733 > \frac{1}{30} \approx 0.033
\]
So, the inequality does not hold in \((3, 4)\).

#### Interval \((4, \infty)\)
Choose \(x = 5\):
\[
\frac{1}{5 - 1} - \frac{4}{5 - 2} + \frac{4}{5 - 3} - \frac{1}{5 - 4} = \frac{1}{4} - \frac{4}{3} + 2 - 1 = 0.25 - 1.333 + 2 - 1 = -0.083 < \frac{1}{30} \approx 0.033
\]
So, the inequality holds in \((4, \infty)\).

### Step 4: Combine the intervals
The inequality holds in \((-\infty, 1) \cup (2, 3) \cup (4, \infty)\).
