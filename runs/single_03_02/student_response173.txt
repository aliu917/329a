Given that \( f(x) \) is a linear function, we can express it in the form \( f(x) = ax + b \). Since \( f \) is linear, its inverse \( f^{-1}(x) \) will also be linear. For a linear function \( f(x) = ax + b \), the inverse function is given by \( f^{-1}(x) = \frac{x - b}{a} \).

We are given the equation \( f(x) = 4f^{-1}(x) + 6 \). Substituting the expression for \( f^{-1}(x) \) into this equation, we get:
\[ ax + b = 4 \left( \frac{x - b}{a} \right) + 6. \]

To eliminate the fraction, multiply both sides by \( a \):
\[ a^2 x + ab = 4(x - b) + 6a. \]
\[ a^2 x + ab = 4x - 4b + 6a. \]

Now, we can collect like terms:
\[ a^2 x - 4x = -4b + 6a - ab. \]
\[ (a^2 - 4)x = 6a - ab - 4b. \]

For this equation to hold for all \( x \), the coefficients of \( x \) on both sides must be equal, and the constant terms must be equal. Therefore, we have two equations:
1. \( a^2 - 4 = 0 \)
2. \( 6a - ab - 4b = 0 \)

From the first equation, we solve for \( a \):
\[ a^2 - 4 = 0 \]
\[ a^2 = 4 \]
\[ a = 2 \text{ or } a = -2. \]

We will consider each case separately.

**Case 1: \( a = 2 \)**
Substitute \( a = 2 \) into the second equation:
\[ 6(2) - (2)b - 4b = 0 \]
\[ 12 - 2b - 4b = 0 \]
\[ 12 - 6b = 0 \]
\[ 12 = 6b \]
\[ b = 2. \]

So, in this case, the function is \( f(x) = 2x + 2 \).

**Case 2: \( a = -2 \)**
Substitute \( a = -2 \) into the second equation:
\[ 6(-2) - (-2)b - 4b = 0 \]
\[ -12 + 2b - 4b = 0 \]
\[ -12 - 2b = 0 \]
\[ -12 = 2b \]
\[ b = -6. \]

So, in this case, the function is \( f(x) = -2x - 6 \).

We are also given that \( f(1) = 4 \). Let's check which of the functions satisfies this condition.

For \( f(x) = 2x + 2 \):
\[ f(1) = 2(1) + 2 = 4. \]
This satisfies the condition.

For \( f(x) = -2x - 6 \):
\[ f(1) = -2(1) - 6 = -8. \]
This does not satisfy the condition.

Therefore, the function is \( f(x) = 2x + 2 \). To find \( f(2) \):
\[ f(2) = 2(2) + 2 = 4 + 2 = 6. \]

The final answer is \(\boxed{6}\).
