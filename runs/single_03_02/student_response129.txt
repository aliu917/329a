To find the unit vector \(\mathbf{v}\) such that \(\mathbf{b}\) bisects the angle between \(\mathbf{a}\) and \(\mathbf{v}\), we will use the angle bisector property of vectors. According to the angle bisector theorem, the vector \(\mathbf{b}\) can be expressed as a linear combination of the unit vectors in the directions of \(\mathbf{a}\) and \(\mathbf{v}\):

\[
\mathbf{b} = k(\hat{\mathbf{a}} + \hat{\mathbf{v}})
\]

where \(\hat{\mathbf{a}}\) and \(\hat{\mathbf{v}}\) are the unit vectors in the directions of \(\mathbf{a}\) and \(\mathbf{v}\), respectively, and \(k\) is a scalar.

First, we find the unit vector \(\hat{\mathbf{a}}\):

\[
\hat{\mathbf{a}} = \frac{\mathbf{a}}{\|\mathbf{a}\|} = \frac{1}{\sqrt{3^2 + 4^2 + 0^2}} \begin{pmatrix} 3 \\ 4 \\ 0 \end{pmatrix} = \frac{1}{5} \begin{pmatrix} 3 \\ 4 \\ 0 \end{pmatrix} = \begin{pmatrix} \frac{3}{5} \\ \frac{4}{5} \\ 0 \end{pmatrix}
\]

Next, we write \(\mathbf{b}\) in terms of \(\hat{\mathbf{a}}\) and \(\hat{\mathbf{v}}\):

\[
\mathbf{b} = k \left( \hat{\mathbf{a}} + \hat{\mathbf{v}} \right)
\]

Given \(\mathbf{b} = \begin{pmatrix} -1 \\ 1 \\ -1 \end{pmatrix}\), we equate:

\[
\begin{pmatrix} -1 \\ 1 \\ -1 \end{pmatrix} = k \left( \begin{pmatrix} \frac{3}{5} \\ \frac{4}{5} \\ 0 \end{pmatrix} + \hat{\mathbf{v}} \right)
\]

Let \(\hat{\mathbf{v}} = \begin{pmatrix} v_1 \\ v_2 \\ v_3 \end{pmatrix}\). Then:

\[
\begin{pmatrix} -1 \\ 1 \\ -1 \end{pmatrix} = k \begin{pmatrix} \frac{3}{5} + v_1 \\ \frac{4}{5} + v_2 \\ v_3 \end{pmatrix}
\]

This gives us the system of equations:

\[
-1 = k \left( \frac{3}{5} + v_1 \right)
\]
\[
1 = k \left( \frac{4}{5} + v_2 \right)
\]
\[
-1 = k v_3
\]

From the third equation, we solve for \(k\):

\[
k = \frac{-1}{v_3}
\]

Substitute \(k\) into the first and second equations:

\[
-1 = \frac{-1}{v_3} \left( \frac{3}{5} + v_1 \right) \implies v_3 = \frac{3}{5} + v_1
\]

\[
1 = \frac{-1}{v_3} \left( \frac{4}{5} + v_2 \right) \implies v_3 = \frac{4}{5} + v_2
\]

Equating the two expressions for \(v_3\):

\[
\frac{3}{5} + v_1 = \frac{4}{5} + v_2 \implies v_1 - v_2 = \frac{1}{5}
\]

Since \(\hat{\mathbf{v}}\) is a unit vector, we have:

\[
v_1^2 + v_2^2 + v_3^2 = 1
\]

Substitute \(v_3 = \frac{3}{5} + v_1\) into the unit vector equation:

\[
v_1^2 + v_2^2 + \left( \frac{3}{5} + v_1 \right)^2 = 1
\]

Expanding and simplifying:

\[
v_1^2 + v_2^2 + \left( \frac{9}{25} + \frac{6}{5}v_1 + v_1^2 \right) = 1
\]
\[
2v_1^2 + v_2^2 + \frac{9}{25} + \frac{6}{5}v_1 = 1
\]
\[
2v_1^2 + v_2^2 + \frac{6}{5}v_1 + \frac{9}{25} = 1
\]
\[
2v_1^2 + v_2^2 + \frac{6}{5}v_1 = \frac{16}{25}
\]

Using \(v_1 - v_2 = \frac{1}{5}\), solve for \(v_2\):

\[
v_2 = v_1 - \frac{1}{5}
\]

Substitute \(v_2\) into the unit vector equation:

\[
2v_1^2 + \left( v_1 - \frac{1}{5} \right)^2 + \frac{6}{5}v_1 = \frac{16}{25}
\]

Simplify and solve for \(v_1\):

\[
2v_1^2 + v_1^2 - \frac{2}{5}v_1 + \frac{1}{25} + \frac{6}{5}v_1 = \frac{16}{25}
\]
\[
3v_1^2 + \frac{4}{5}v_1 + \frac{1}{25} = \frac{16}{25}
\]
\[
3v_1^2 + \frac{4}{5}v_1 - \frac{15}{25} = 0
\]
\[
3v_1^2 + \frac{4}{5}v_1 - \frac{3}{5} = 0
\]

Multiply through by 5 to clear the fraction:

\[
15v_1^2 + 4v_1 - 3 = 0
\]

Solve this quadratic equation using the quadratic formula \(v_1 = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\):

\[
v_1 = \frac{-4 \pm \sqrt{16 + 180}}{30} = \frac{-4 \pm \sqrt{196}}{30} = \frac{-4 \pm 14}{30}
\]

Thus, \(v_1 = \frac{10}{30} = \frac{1}{3}\) or \(v_1 = \frac{-18}{30} = -\frac{3}{5}\).

If \(v_1 = \frac{1}{3}\), then \(v_2 = -\frac{2}{15}\) and \(v_3 = \frac{3}{5} + \frac{1}{3} = \frac{14}{15}\).

If \(v_1 = -\frac{3}{5}\), then \(v_2 = -\frac{8}{15}\) and \(v_3 = \frac{3}{5} - \frac{3}{5} = 0\).

The valid unit vector is:

\[
\boxed{\begin{pmatrix} \frac{1}{3} \\ -\frac{2}{15} \\ \frac{14}{15} \end{pmatrix}}
\]
