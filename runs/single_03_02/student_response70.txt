First, recall the identity for the sum of cubes when the sum of the numbers is zero:
\[a^3 + b^3 + c^3 - 3abc = (a+b+c)(a^2 + b^2 + c^2 - ab - bc - ca).\]
Since \(a + b + c = 0\), the identity simplifies to:
\[a^3 + b^3 + c^3 = 3abc.\]
Given \(a^3 + b^3 + c^3 = a^5 + b^5 + c^5\), we can substitute to get:
\[3abc = a^5 + b^5 + c^5.\]

\[a + (-a) + 0 = 0,\]
which is true. Now, we need to check if this satisfies the other given equation:
\[a^3 + (-a)^3 + 0^3 = a^5 + (-a)^5 + 0^5.\]
This simplifies to:
\[a^3 - a^3 = a^5 - a^5,\]
which is true. Therefore, \(a = -b\) and \(c = 0\) is a valid solution.

\[a^2 + (-a)^2 + 0^2 = a^2 + a^2 = 2a^2.\]
