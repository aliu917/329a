   \[
   \frac{x + y}{2} \geq \sqrt{xy}.
   \]
   Substituting \(x + y = 100\), we get
   \[
   \frac{100}{2} \geq \sqrt{xy} \implies 50 \geq \sqrt{xy} \implies 2500 \geq xy.
   \]
   The equality holds when \(x = y = 50\). Therefore, the maximum value of \(xy\) is 2500 when \(x = 50\) and \(y = 50\).

4. **Verify the solution**: If \(w = 0\), \(x = 50\), \(y = 50\), and \(z = 0\), then the expression \(wx + xy + yz\) becomes
   \[
   wx + xy + yz = 0 \cdot 50 + 50 \cdot 50 + 50 \cdot 0 = 2500.
   \]
   This confirms that the maximum value of \(wx + xy + yz\) is indeed 2500.
