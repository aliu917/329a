To solve the given problem, we start with the equation:

\[
\frac{ \left( \frac{1}{2} \right)^2 + \left( \frac{1}{3} \right)^2 }{ \left( \frac{1}{4} \right)^2 + \left( \frac{1}{5} \right)^2 } = \frac{13x}{41y}
\]

First, we simplify the left-hand side of the equation. We calculate the squares of the fractions:

\[
\left( \frac{1}{2} \right)^2 = \frac{1}{4}
\]
\[
\left( \frac{1}{3} \right)^2 = \frac{1}{9}
\]
\[
\left( \frac{1}{4} \right)^2 = \frac{1}{16}
\]
\[
\left( \frac{1}{5} \right)^2 = \frac{1}{25}
\]

Next, we substitute these values back into the equation:

\[
\frac{ \frac{1}{4} + \frac{1}{9} }{ \frac{1}{16} + \frac{1}{25} }
\]

To add the fractions in the numerator, we find a common denominator for \(\frac{1}{4}\) and \(\frac{1}{9}\). The least common multiple of 4 and 9 is 36:

\[
\frac{1}{4} = \frac{9}{36}, \quad \frac{1}{9} = \frac{4}{36}
\]

Thus,

\[
\frac{1}{4} + \frac{1}{9} = \frac{9}{36} + \frac{4}{36} = \frac{13}{36}
\]

For the denominator, we find a common denominator for \(\frac{1}{16}\) and \(\frac{1}{25}\). The least common multiple of 16 and 25 is 400:

\[
\frac{1}{16} = \frac{25}{400}, \quad \frac{1}{25} = \frac{16}{400}
\]

Thus,

\[
\frac{1}{16} + \frac{1}{25} = \frac{25}{400} + \frac{16}{400} = \frac{41}{400}
\]

Now we substitute these simplified fractions back into the equation:

\[
\frac{ \frac{13}{36} }{ \frac{41}{400} }
\]

Dividing by a fraction is equivalent to multiplying by its reciprocal:

\[
\frac{ \frac{13}{36} }{ \frac{41}{400} } = \frac{13}{36} \times \frac{400}{41} = \frac{13 \times 400}{36 \times 41} = \frac{5200}{1476}
\]

We simplify \(\frac{5200}{1476}\) by finding the greatest common divisor (GCD) of 5200 and 1476. The GCD is 4:

\[
\frac{5200 \div 4}{1476 \div 4} = \frac{1300}{369}
\]

Thus, we have:

\[
\frac{13x}{41y} = \frac{1300}{369}
\]

By comparing the numerators and denominators, we find:

\[
13x = 1300 \quad \text{and} \quad 41y = 369
\]

Solving for \(x\) and \(y\):

\[
x = \frac{1300}{13} = 100
\]
\[
y = \frac{369}{41} = 9
\]

Now, we need to find \(\sqrt{x} \div \sqrt{y}\):

\[
\sqrt{x} \div \sqrt{y} = \sqrt{100} \div \sqrt{9} = \frac{\sqrt{100}}{\sqrt{9}} = \frac{10}{3}
\]

Thus, the final answer is:

\[
\boxed{\frac{10}{3}}
\]
