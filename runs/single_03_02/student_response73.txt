Given the equations:
\[
\frac{\sin x}{\cos y} + \frac{\sin y}{\cos x} = 1
\]
\[
\frac{\cos x}{\sin y} + \frac{\cos y}{\sin x} = 6
\]

We start by letting \( a = \tan x \) and \( b = \tan y \). Then we have:
\[
\frac{\sin x}{\cos y} = \frac{\tan x}{\cos y / \cos x} = \frac{a \cos x}{\cos y} = a \frac{\cos x}{\cos y} = a \frac{1}{\tan y} = \frac{a}{b}
\]
\[
\frac{\sin y}{\cos x} = \frac{\tan y}{\cos x / \cos y} = \frac{b \cos y}{\cos x} = b \frac{\cos y}{\cos x} = b \frac{1}{\tan x} = \frac{b}{a}
\]
Thus, the first equation becomes:
\[
\frac{a}{b} + \frac{b}{a} = 1
\]
Multiplying both sides by \( ab \) gives:
\[
a^2 + b^2 = ab
\]

Next, we consider the second equation:
\[
\frac{\cos x}{\sin y} + \frac{\cos y}{\sin x} = 6
\]
Using the identity \( \cos x = \frac{1}{\sqrt{1 + \tan^2 x}} \) and \( \sin x = \frac{\tan x}{\sqrt{1 + \tan^2 x}} \), we get:
\[
\frac{\cos x}{\sin y} = \frac{1/\sqrt{1 + a^2}}{\sin y} = \frac{1}{\sqrt{1 + a^2} \sin y}
\]
\[
\frac{\cos y}{\sin x} = \frac{1/\sqrt{1 + b^2}}{\sin x} = \frac{1}{\sqrt{1 + b^2} \sin x}
\]
However, a simpler approach is to use the identity \( \frac{\cos x}{\sin y} = \frac{\cos x / \cos y}{\sin y / \cos y} = \frac{\cos x / \cos y}{\tan y} = \frac{1}{b \tan x} = \frac{1}{ab} \) and similarly for the other term. Thus, the second equation becomes:
\[
\frac{1}{ab} + \frac{1}{ab} = 6 \implies \frac{2}{ab} = 6 \implies ab = \frac{1}{3}
\]

Now we have the system:
\[
a^2 + b^2 = ab
\]
\[
ab = \frac{1}{3}
\]

Substituting \( ab = \frac{1}{3} \) into \( a^2 + b^2 = ab \) gives:
\[
a^2 + b^2 = \frac{1}{3}
\]
We need to find \( \frac{\tan x}{\tan y} + \frac{\tan y}{\tan x} = \frac{a}{b} + \frac{b}{a} \). Let \( k = \frac{a}{b} \), then:
\[
\frac{a}{b} + \frac{b}{a} = k + \frac{1}{k}
\]
From \( a^2 + b^2 = ab \) and \( ab = \frac{1}{3} \), we have:
\[
a^2 + b^2 = \frac{1}{3} \implies \left( \frac{a}{b} \right)^2 + 1 = \frac{1}{3} \cdot \frac{1}{b^2} = \frac{1}{3a^2} \implies k^2 + 1 = \frac{1}{3k^2} \implies 3k^4 + 3k^2 = 1 \implies 3k^4 + 3k^2 - 1 = 0
\]
Let \( u = k^2 \), then:
\[
3u^2 + 3u - 1 = 0
\]
Solving this quadratic equation using the quadratic formula \( u = \frac{-3 \pm \sqrt{9 + 12}}{6} = \frac{-3 \pm \sqrt{21}}{6} \). Since \( u = k^2 \) must be positive:
\[
u = \frac{-3 + \sqrt{21}}{6} \implies k^2 = \frac{-3 + \sqrt{21}}{6} \implies k = \sqrt{\frac{-3 + \sqrt{21}}{6}}
\]
Thus:
\[
\frac{a}{b} + \frac{b}{a} = k + \frac{1}{k} = \sqrt{\frac{-3 + \sqrt{21}}{6}} + \sqrt{\frac{6}{-3 + \sqrt{21}}} = \sqrt{\frac{-3 + \sqrt{21}}{6}} + \sqrt{\frac{6}{-3 + \sqrt{21}}} = \sqrt{\frac{-3 + \sqrt{21}}{6}} + \sqrt{\frac{6}{-3 + \sqrt{21}}} = 2
\]

Therefore, the answer is:
\[
\boxed{2}
\]
