To solve the problem, we start by interpreting the given equation geometrically. The equation \(|z - 3i| + |z - 4| = 5\) describes the set of points \(z\) in the complex plane such that the sum of the distances from \(z\) to the points \(3i\) (which is \((0,3)\) in Cartesian coordinates) and \(4\) (which is \((4,0)\)) is constant and equal to 5. This is the definition of an ellipse with foci at \((0,3)\) and \((4,0)\) and a major axis length of 5.

First, we need to check if the distance between the foci is less than the sum of the distances to the foci. The distance between the foci is calculated as follows:
\[
\sqrt{(4-0)^2 + (0-3)^2} = \sqrt{16 + 9} = \sqrt{25} = 5.
\]
Since the distance between the foci is equal to the sum of the distances to the foci, the ellipse degenerates into the line segment joining the points \((0,3)\) and \((4,0)\).

Next, we need to find the minimum value of \(|z|\), which is the distance from the origin to any point on this line segment. The equation of the line segment can be parameterized as:
\[
z = (1-t)(4,0) + t(0,3) = (4-4t, 3t), \quad 0 \le t \le 1.
\]
The distance from the origin to a point \((4-4t, 3t)\) is given by:
\[
|z| = \sqrt{(4-4t)^2 + (3t)^2} = \sqrt{16 - 32t + 16t^2 + 9t^2} = \sqrt{25t^2 - 32t + 16}.
\]
To find the minimum value of this expression, we can complete the square or use calculus. Here, we complete the square:
\[
25t^2 - 32t + 16 = 25\left(t^2 - \frac{32}{25}t\right) + 16 = 25\left(t - \frac{16}{25}\right)^2 + 16 - 25\left(\frac{16}{25}\right)^2 = 25\left(t - \frac{16}{25}\right)^2 + \frac{144}{25}.
\]
The minimum value of \(25\left(t - \frac{16}{25}\right)^2 + \frac{144}{25}\) is \(\frac{144}{25}\) when \(t = \frac{16}{25}\). Therefore, the minimum value of \(|z|\) is:
\[
\sqrt{\frac{144}{25}} = \frac{12}{5}.
\]
Thus, the minimum value of \(|z|\) is \(\boxed{\frac{12}{5}}\).
