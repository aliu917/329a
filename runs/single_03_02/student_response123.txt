To solve the problem, we start by interpreting the given equation geometrically. The equation \(|z - 3i| + |z - 4| = 5\) represents the set of points \(z\) in the complex plane such that the sum of the distances from \(z\) to the points \(3i\) (which is \((0,3)\)) and \(4\) (which is \((4,0)\)) is constant and equal to 5. This is the definition of an ellipse with foci at \((0,3)\) and \((4,0)\) and the major axis length equal to 5.

First, we calculate the distance between the foci:
\[
\sqrt{(4-0)^2 + (0-3)^2} = \sqrt{16 + 9} = 5.
\]
Since the distance between the foci is equal to the length of the major axis, the ellipse degenerates into a line segment connecting the points \((0,3)\) and \((4,0)\).

Next, we need to find the point on this line segment that is closest to the origin. The equation of the line passing through \((0,3)\) and \((4,0)\) can be found using the two-point form of the line equation:
\[
y - 3 = \frac{0-3}{4-0}(x-0) \implies y - 3 = -\frac{3}{4}x \implies y = -\frac{3}{4}x + 3.
\]
To find the point on this line that is closest to the origin, we use the fact that the shortest distance from a point to a line is along the perpendicular from the point to the line. The slope of the line is \(-\frac{3}{4}\), so the slope of the perpendicular line is \(\frac{4}{3}\). The equation of the line passing through the origin with slope \(\frac{4}{3}\) is:
\[
y = \frac{4}{3}x.
\]
We find the intersection of the lines \(y = -\frac{3}{4}x + 3\) and \(y = \frac{4}{3}x\):
\[
\frac{4}{3}x = -\frac{3}{4}x + 3 \implies \frac{4}{3}x + \frac{3}{4}x = 3 \implies \frac{16x + 9x}{12} = 3 \implies \frac{25x}{12} = 3 \implies x = \frac{36}{25}.
\]
Substituting \(x = \frac{36}{25}\) back into \(y = \frac{4}{3}x\):
\[
y = \frac{4}{3} \cdot \frac{36}{25} = \frac{48}{25}.
\]
Thus, the point on the line segment that is closest to the origin is \(\left(\frac{36}{25}, \frac{48}{25}\right)\). The distance from the origin to this point is:
\[
\sqrt{\left(\frac{36}{25}\right)^2 + \left(\frac{48}{25}\right)^2} = \sqrt{\frac{1296}{625} + \frac{2304}{625}} = \sqrt{\frac{3600}{625}} = \sqrt{\frac{144}{25}} = \frac{12}{5}.
\]
