Let's analyze each option one by one, given that \(a < 0\) and \(a < b < c\).

1. **Option A: \(ab < bc\)**

   Since \(a < b\), we can multiply both sides by \(b\) (which is positive or negative, but the sign will be the same as \(b\)). We need to consider the sign of \(b\):
   - If \(b > 0\), then \(ab < b^2\) (since \(a < b\)), and since \(b < c\), \(b^2 < bc\), so \(ab < bc\).
   - If \(b < 0\), then \(ab > b^2\) (since \(a < b\)), and since \(b < c\), \(b^2 > bc\), so \(ab > bc\).

   Therefore, \(ab < bc\) is not always true.

2. **Option B: \(ac < bc\)**

   Since \(a < b\) and \(c > 0\) (because \(a < b < c\) and \(a < 0\)), multiplying both sides of \(a < b\) by \(c\) (which is positive) gives \(ac < bc\). This is always true.

3. **Option C: \(ab < ac\)**

   Since \(a < 0\) and \(b < c\), multiplying both sides of \(b < c\) by \(a\) (which is negative) reverses the inequality, so \(ab > ac\). Therefore, \(ab < ac\) is not true.

4. **Option D: \(a + b < b + c\)**

   Subtracting \(b\) from both sides, we get \(a < c\), which is true by the given condition \(a < b < c\). Therefore, \(a + b < b + c\) is always true.

5. **Option E: \(\frac{c}{a} < 1\)**

   Since \(a < 0\) and \(c > 0\), \(\frac{c}{a}\) is negative (because a negative divided by a positive is negative). Therefore, \(\frac{c}{a} < 1\) is always true.
