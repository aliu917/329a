To determine the number of trailing zeros in the product \(1! \cdot 2! \cdot 3! \cdots 99! \cdot 100!\), we need to count the number of times 10 is a factor in this product. Since \(10 = 2 \times 5\) and there are generally more factors of 2 than 5 in factorials, we only need to count the number of times 5 is a factor in the product.

The number of times 5 is a factor in \(n!\) is given by:
\[
\left\lfloor \frac{n}{5} \right\rfloor + \left\lfloor \frac{n}{25} \right\rfloor + \left\lfloor \frac{n}{125} \right\rfloor + \cdots
\]
We need to sum this for each factorial from \(1!\) to \(100!\).

First, we calculate the number of times 5 is a factor in \(100!\):
\[
\left\lfloor \frac{100}{5} \right\rfloor + \left\lfloor \frac{100}{25} \right\rfloor + \left\lfloor \frac{100}{125} \right\rfloor = 20 + 4 + 0 = 24
\]

Next, we calculate the number of times 5 is a factor in \(99!\):
\[
\left\lfloor \frac{99}{5} \right\rfloor + \left\lfloor \frac{99}{25} \right\rfloor + \left\lfloor \frac{99}{125} \right\rfloor = 19 + 3 + 0 = 22
\]

We continue this process for each factorial from \(98!\) to \(1!\). The number of times 5 is a factor in \(n!\) decreases as \(n\) decreases. We can sum these values for all factorials from \(1!\) to \(100!\).

The total number of times 5 is a factor in the product \(1! \cdot 2! \cdot 3! \cdots 99! \cdot 100!\) is:
\[
\sum_{n=1}^{100} \left( \left\lfloor \frac{n}{5} \right\rfloor + \left\lfloor \frac{n}{25} \right\rfloor + \left\lfloor \frac{n}{125} \right\rfloor + \cdots \right)
\]

We can break this into parts:
\[
\sum_{n=1}^{100} \left\lfloor \frac{n}{5} \right\rfloor + \sum_{n=1}^{100} \left\lfloor \frac{n}{25} \right\rfloor + \sum_{n=1}^{100} \left\lfloor \frac{n}{125} \right\rfloor + \cdots
\]

Calculating each part:
\[
\sum_{n=1}^{100} \left\lfloor \frac{n}{5} \right\rfloor = 20 + 19 + 18 + \cdots + 1 + 0 = \frac{20 \cdot 21}{2} = 210
\]
\[
\sum_{n=1}^{100} \left\lfloor \frac{n}{25} \right\rfloor = 4 + 4 + 4 + \cdots + 4 + 0 = 4 \cdot 4 = 16
\]
\[
\sum_{n=1}^{100} \left\lfloor \frac{n}{125} \right\rfloor = 0
\]

Summing these values:
\[
210 + 16 + 0 + \cdots = 226
\]

Thus, the number of trailing zeros in the product \(1! \cdot 2! \cdot 3! \cdots 99! \cdot 100!\) is 226. The remainder when 226 is divided by 1000 is:
\[
\boxed{226}
