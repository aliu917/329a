Let's analyze each inequality step by step given the conditions \(a < 0\) and \(a < b < c\).

1. **Inequality \(ab < bc\):**
   - Since \(b < c\), and \(a < 0\), we need to consider the sign of \(a\).
   - When we multiply both sides of \(b < c\) by the negative number \(a\), the inequality reverses: \(ab > ac\).
   - Since \(b < c\), \(bc > ac\).
   - Combining these, we have \(ab > ac < bc\), which simplifies to \(ab > bc\), not \(ab < bc\).
   - Therefore, this inequality is **false**.

2. **Inequality \(ac < bc\):**
   - Since \(a < b\) and \(a < 0\), multiplying both sides by the positive number \(c\) (since \(c > a\) and \(a < 0\) implies \(c > 0\)) does not change the inequality: \(ac < bc\).
   - Therefore, this inequality is **true**.

3. **Inequality \(ab < ac\):**
   - As previously analyzed, multiplying both sides of \(b < c\) by the negative number \(a\) reverses the inequality: \(ab > ac\).
   - Therefore, this inequality is **false**.

4. **Inequality \(a + b < b + c\):**
   - Subtract \(b\) from both sides: \(a < c\).
   - This is true by the given condition \(a < b < c\).
   - Therefore, this inequality is **true**.

5. **Inequality \(\frac{c}{a} < 1\):**
   - Since \(a < 0\) and \(c > 0\), \(\frac{c}{a}\) is negative (because the quotient of a positive and a negative number is negative).
   - Any negative number is less than 1.
   - Therefore, this inequality is **true**.
