To solve for \(\sin(2 \angle BPC)\), we start by analyzing the given information and the relationships between the angles. Let's denote the lengths \(AB = BC = CD = x\).

First, let's place the points on a coordinate line for simplicity. Assume \(A = 0\), \(B = x\), \(C = 2x\), and \(D = 3x\). Let the coordinates of point \(P\) be \((a, b)\).

The cosine of the angles \(\angle APC\) and \(\angle BPD\) are given as \(\cos \angle APC = \frac{4}{5}\) and \(\cos \angle BPD = \frac{3}{5}\). We need to find \(\sin(2 \angle BPC)\).

Since \(\cos \angle APC = \frac{4}{5}\), we have:
\[
\cos \angle APC = \frac{\overrightarrow{PA} \cdot \overrightarrow{PC}}{PA \cdot PC} = \frac{4}{5}
\]
Similarly, for \(\cos \angle BPD = \frac{3}{5}\), we have:
\[
\cos \angle BPD = \frac{\overrightarrow{PB} \cdot \overrightarrow{PD}}{PB \cdot PD} = \frac{3}{5}
\]

We need to find \(\sin(2 \angle BPC)\). Using the identity \(\sin(2\theta) = 2 \sin \theta \cos \theta\), we need to find \(\sin \angle BPC\) and \(\cos \angle BPC\).

Notice that \(\angle APC + \angle BPD = 90^\circ\). This is because the vectors \(\overrightarrow{PA}\), \(\overrightarrow{PC}\) and \(\overrightarrow{PB}\), \(\overrightarrow{PD}\) are related in such a way that the angles they form are complementary. Therefore, \(\angle APC\) and \(\angle BPD\) are complementary angles.

Since \(\angle APC + \angle BPD = 90^\circ\), we have:
\[
\angle APC = 90^\circ - \angle BPD
\]
Thus,
\[
\sin \angle APC = \cos \angle BPD = \frac{3}{5}
\]
and
\[
\cos \angle APC = \sin \angle BPD = \frac{4}{5}
\]

Now, we need to find \(\sin \angle BPC\) and \(\cos \angle BPC\). Using the fact that \(\angle APC = 90^\circ - \angle BPD\), we can use the identity:
\[
\sin(90^\circ - \theta) = \cos \theta
\]
and
\[
\cos(90^\circ - \theta) = \sin \theta
\]

Therefore,
\[
\sin \angle BPC = \sin(90^\circ - \angle APC) = \cos \angle APC = \frac{4}{5}
\]
and
\[
\cos \angle BPC = \cos(90^\circ - \angle APC) = \sin \angle APC = \frac{3}{5}
\]

Finally, we use the double angle formula for sine:
\[
\sin(2 \angle BPC) = 2 \sin \angle BPC \cos \angle BPC = 2 \left(\frac{4}{5}\right) \left(\frac{3}{5}\right) = 2 \cdot \frac{12}{25} = \frac{24}{25}
\]

Thus, the answer is:
\[
