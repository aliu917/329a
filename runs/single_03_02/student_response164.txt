To solve the equation \(\tan \theta + \tan 2\theta + \tan 3\theta = 0\) for \(0^\circ < \theta < 45^\circ\), we will use the tangent addition formulas and properties of the tangent function.

First, recall the double-angle and triple-angle formulas for tangent:
\[
\tan 2\theta = \frac{2\tan \theta}{1 - \tan^2 \theta}
\]
\[
\tan 3\theta = \frac{3\tan \theta - \tan^3 \theta}{1 - 3\tan^2 \theta}
\]

Let \(x = \tan \theta\). Then the equation becomes:
\[
x + \frac{2x}{1 - x^2} + \frac{3x - x^3}{1 - 3x^2} = 0
\]

To simplify, we find a common denominator for the fractions:
\[
x + \frac{2x(1 - 3x^2) + (3x - x^3)(1 - x^2)}{(1 - x^2)(1 - 3x^2)} = 0
\]

Simplify the numerator:
\[
x + \frac{2x - 6x^3 + 3x - 3x^3 - x^3 + x^5}{(1 - x^2)(1 - 3x^2)} = 0
\]
\[
x + \frac{5x - 10x^3 + x^5}{(1 - x^2)(1 - 3x^2)} = 0
\]

Combine the terms in the numerator:
\[
x + \frac{x(5 - 10x^2 + x^4)}{(1 - x^2)(1 - 3x^2)} = 0
\]

Factor out \(x\) from the numerator:
\[
x \left(1 + \frac{5 - 10x^2 + x^4}{(1 - x^2)(1 - 3x^2)}\right) = 0
\]

Since \(x \neq 0\) (because \(0^\circ < \theta < 45^\circ\)), we have:
\[
1 + \frac{5 - 10x^2 + x^4}{(1 - x^2)(1 - 3x^2)} = 0
\]

Solve for \(x\):
\[
\frac{5 - 10x^2 + x^4}{(1 - x^2)(1 - 3x^2)} = -1
\]
\[
5 - 10x^2 + x^4 = -(1 - x^2)(1 - 3x^2)
\]
\[
5 - 10x^2 + x^4 = -1 + 3x^2 + x^2 - 3x^4
\]
\[
5 - 10x^2 + x^4 = -1 + 4x^2 - 3x^4
\]
\[
4x^4 - 14x^2 + 6 = 0
\]
\[
2x^4 - 7x^2 + 3 = 0
\]

Let \(y = x^2\). Then the equation becomes:
\[
2y^2 - 7y + 3 = 0
\]

Solve this quadratic equation using the quadratic formula \(y = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\):
\[
y = \frac{7 \pm \sqrt{49 - 24}}{4}
\]
\[
y = \frac{7 \pm 5}{4}
\]
\[
y = 3 \quad \text{or} \quad y = \frac{1}{2}
\]

Since \(y = x^2\) and \(0^\circ < \theta < 45^\circ\), we have \(0 < x < 1\). Therefore, \(y = \frac{1}{2}\).

Thus:
\[
x^2 = \frac{1}{2}
\]
\[
x = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}
\]

The value of \(\tan \theta\) is:
\[
\boxed{\frac{\sqrt{2}}{2}}
\]
