To determine the number of connections necessary in a network where each of the 20 switches is directly connected to exactly three other switches, we can follow these steps:

1. **Calculate the total number of "ends" of connections:**
   Each switch has 3 connections, and there are 20 switches. Therefore, the total number of "ends" of connections is:
   \[
   20 \times 3 = 60
   \]

2. **Understand that each connection is counted twice:**
   Each connection involves two switches, so the total number of connections is half the total number of "ends" of connections. This is because each connection is counted once at each end. Therefore, the total number of connections is:
   \[
   \frac{60}{2} = 30
   \]

So, the number of connections necessary is \(\boxed{30}\).
