To find the probability that the sum of the numbers rolled on three six-faced dice is 9, we need to follow these steps:

1. **Determine the total number of possible outcomes:**
   Each die has 6 faces, so when three dice are rolled, the total number of possible outcomes is:
   \[
   6 \times 6 \times 6 = 216
   \]

2. **Find the number of favorable outcomes where the sum is 9:**
   We need to find the number of solutions to the equation \(x_1 + x_2 + x_3 = 9\) where \(1 \leq x_i \leq 6\) for \(i = 1, 2, 3\). First, we transform the variables to simplify counting. Let \(y_i = x_i - 1\). Then \(0 \leq y_i \leq 5\) and the equation becomes:
   \[
   (y_1 + 1) + (y_2 + 1) + (y_3 + 1) = 9 \implies y_1 + y_2 + y_3 = 6
   \]
   Now we need to find the number of non-negative integer solutions to \(y_1 + y_2 + y_3 = 6\) such that \(0 \leq y_i \leq 5\). Using the stars and bars method, the number of solutions without any restrictions is:
   \[
   \binom{6 + 3 - 1}{3 - 1} = \binom{8}{2} = 28
   \]
   However, we need to subtract the cases where one or more \(y_i\) is greater than 5. If \(y_1 > 5\), let \(y_1' = y_1 - 6\), then \(y_1' \geq 0\) and the equation becomes:
   \[
   y_1' + y_2 + y_3 = 0
   \]
   The number of solutions to this equation is:
   \[
   \binom{0 + 3 - 1}{3 - 1} = \binom{2}{2} = 1
   \]
   Since any of the three variables could be the one that is greater than 5, we multiply by 3:
   \[
   3 \times 1 = 3
   \]
   Therefore, the number of valid solutions is:
   \[
   28 - 3 = 25
   \]
   So, there are 25 favorable outcomes.

3. **Calculate the probability:**
   The probability is the number of favorable outcomes divided by the total number of possible outcomes:
   \[
   \frac{25}{216}
   \]

Thus, the probability that the sum of the numbers rolled on three six-faced dice is 9 is \(\boxed{\frac{25}{216}}\).
