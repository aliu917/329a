To solve the problem, we need to find the least positive value of \( t \) such that the sequence \(\arcsin (\sin \alpha), \ \arcsin (\sin 2 \alpha), \ \arcsin (\sin 7 \alpha), \ \arcsin (\sin t \alpha)\) forms a geometric progression for some \(\alpha\) with \(0 < \alpha < \frac{\pi}{2}\).

First, let's denote the common ratio of the geometric progression by \( r \). Therefore, we have:
\[
\arcsin (\sin 2 \alpha) = r \arcsin (\sin \alpha),
\]
\[
\arcsin (\sin 7 \alpha) = r \arcsin (\sin 2 \alpha),
\]
\[
\arcsin (\sin t \alpha) = r \arcsin (\sin 7 \alpha).
\]

We start by analyzing \(\arcsin (\sin \alpha)\). Since \(0 < \alpha < \frac{\pi}{2}\), \(\arcsin (\sin \alpha) = \alpha\).

Next, consider \(\arcsin (\sin 2\alpha)\). We need to determine the value of \(\arcsin (\sin 2\alpha)\) based on the value of \(2\alpha\):
- If \(0 < 2\alpha < \pi\), then \(\arcsin (\sin 2\alpha) = 2\alpha\).
- If \(\pi < 2\alpha < 2\pi\), then \(\arcsin (\sin 2\alpha) = \pi - 2\alpha\).

Since \(0 < \alpha < \frac{\pi}{2}\), we have \(0 < 2\alpha < \pi\), so \(\arcsin (\sin 2\alpha) = 2\alpha\).

Now, we use the geometric progression property:
\[
2\alpha = r \alpha.
\]
Solving for \(r\), we get:
\[
r = 2.
\]

Next, consider \(\arcsin (\sin 7\alpha)\). We need to determine the value of \(\arcsin (\sin 7\alpha)\) based on the value of \(7\alpha\):
- If \(0 < 7\alpha < \pi\), then \(\arcsin (\sin 7\alpha) = 7\alpha\).
- If \(\pi < 7\alpha < 2\pi\), then \(\arcsin (\sin 7\alpha) = \pi - 7\alpha\).
- If \(2\pi < 7\alpha < 3\pi\), then \(\arcsin (\sin 7\alpha) = 3\pi - 7\alpha\).

Since \(0 < \alpha < \frac{\pi}{2}\), we have \(0 < 7\alpha < \frac{7\pi}{2}\). We need to find the appropriate range for \(7\alpha\).

Assume \(7\alpha\) falls in the range \(\pi < 7\alpha < 2\pi\):
\[
\arcsin (\sin 7\alpha) = \pi - 7\alpha.
\]

Using the geometric progression property again:
\[
\pi - 7\alpha = 2(2\alpha) = 4\alpha.
\]
Solving for \(\alpha\), we get:
\[
\pi - 7\alpha = 4\alpha,
\]
\[
\pi = 11\alpha,
\]
\[
\alpha = \frac{\pi}{11}.
\]

Finally, we need to find \(t\) such that:
\[
\arcsin (\sin t\alpha) = 2(\pi - 7\alpha).
\]
Substitute \(\alpha = \frac{\pi}{11}\):
\[
\arcsin (\sin t\alpha) = 2\left(\pi - 7 \cdot \frac{\pi}{11}\right) = 2\left(\pi - \frac{7\pi}{11}\right) = 2 \cdot \frac{4\pi}{11} = \frac{8\pi}{11}.
\]

Since \(0 < t\alpha < \frac{11\pi}{2}\), we have:
\[
\arcsin (\sin t\alpha) = t\alpha.
\]
Thus:
\[
t\alpha = \frac{8\pi}{11},
\]
\[
t \cdot \frac{\pi}{11} = \frac{8\pi}{11},
\]
\[
t = 8.
\]

Therefore, the least positive value of \(t\) is:
\[
\boxed{8}.
