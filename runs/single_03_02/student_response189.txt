To find the least positive value of \( t \) such that the sequence \(\arcsin (\sin \alpha), \arcsin (\sin 2\alpha), \arcsin (\sin 7\alpha), \arcsin (\sin t\alpha)\) forms a geometric progression for some \(\alpha\) with \(0 < \alpha < \frac{\pi}{2}\), we start by letting the terms of the geometric progression be \(a, ar, ar^2, ar^3\).

First, we need to determine the possible values of \(\arcsin (\sin x)\) for \(x\) in the interval \((0, \pi)\). The function \(\arcsin (\sin x)\) gives us a value in the interval \([- \frac{\pi}{2}, \frac{\pi}{2}]\). Specifically, for \(0 < x < \frac{\pi}{2}\), \(\arcsin (\sin x) = x\). For \(\frac{\pi}{2} < x < \pi\), \(\arcsin (\sin x) = \pi - x\).

Given the sequence \(\arcsin (\sin \alpha), \arcsin (\sin 2\alpha), \arcsin (\sin 7\alpha), \arcsin (\sin t\alpha)\), we have:
\[
\arcsin (\sin \alpha) = \alpha, \quad \arcsin (\sin 2\alpha) = 2\alpha, \quad \arcsin (\sin 7\alpha) = 7\alpha - \pi, \quad \arcsin (\sin t\alpha) = t\alpha - \pi k
\]
for some integer \(k\) such that \(t\alpha - \pi k\) is in the interval \([- \frac{\pi}{2}, \frac{\pi}{2}]\).

Since \(\alpha, 2\alpha, 7\alpha - \pi, t\alpha - \pi k\) form a geometric progression, we have:
\[
\frac{2\alpha}{\alpha} = \frac{7\alpha - \pi}{2\alpha} = \frac{t\alpha - \pi k}{7\alpha - \pi}
\]
This simplifies to:
\[
2 = \frac{7\alpha - \pi}{2\alpha} = \frac{t\alpha - \pi k}{7\alpha - \pi}
\]
From \(2 = \frac{7\alpha - \pi}{2\alpha}\), we get:
\[
2 \cdot 2\alpha = 7\alpha - \pi \implies 4\alpha = 7\alpha - \pi \implies -3\alpha = -\pi \implies \alpha = \frac{\pi}{3}
\]
Now substituting \(\alpha = \frac{\pi}{3}\) into the next part of the equation:
\[
2 = \frac{t \cdot \frac{\pi}{3} - \pi k}{7 \cdot \frac{\pi}{3} - \pi} = \frac{\frac{t\pi}{3} - \pi k}{\frac{7\pi}{3} - \pi} = \frac{\frac{t\pi - 3\pi k}{3}}{\frac{4\pi}{3}} = \frac{t - 3k}{4}
\]
This gives:
\[
2 = \frac{t - 3k}{4} \implies 8 = t - 3k \implies t = 8 + 3k
\]
The smallest positive value of \(t\) occurs when \(k = 0\), so \(t = 8\).

Thus, the least positive value of \(t\) is \(\boxed{8}\).
