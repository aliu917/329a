The first two terms of a sequence are \$a_1 = 1\$ and \$a_2 = \frac {1}{\sqrt3}\$. For \$n\ge1\$,

To solve the problem, we start by examining the given recurrence relation:
\[ a_{n+2} = \frac{a_n + a_{n+1}}{1 - a_n a_{n+1}} \]

We are given the initial terms:
\[ a_1 = 1 \]
\[ a_2 = \frac{1}{\sqrt{3}} \]

We need to find the value of \( |a_{2009}| \).

First, let's compute the next few terms to identify any patterns.

### Step 1: Compute \( a_3 \)
\[ a_3 = \frac{a_1 + a_2}{1 - a_1 a_2} = \frac{1 + \frac{1}{\sqrt{3}}}{1 - 1 \cdot \frac{1}{\sqrt{3}}} = \frac{1 + \frac{1}{\sqrt{3}}}{1 - \frac{1}{\sqrt{3}}} \]
\[ a_3 = \frac{\frac{\sqrt{3} + 1}{\sqrt{3}}}{\frac{\sqrt{3} - 1}{\sqrt{3}}} = \frac{\sqrt{3} + 1}{\sqrt{3} - 1} \]
Rationalize the denominator:
\[ a_3 = \frac{(\sqrt{3} + 1)(\sqrt{3} + 1)}{(\sqrt{3} - 1)(\sqrt{3} + 1)} = \frac{(\sqrt{3} + 1)^2}{3 - 1} = \frac{3 + 2\sqrt{3} + 1}{2} = \frac{4 + 2\sqrt{3}}{2} = 2 + \sqrt{3} \]

### Step 2: Compute \( a_4 \)
\[ a_4 = \frac{a_2 + a_3}{1 - a_2 a_3} = \frac{\frac{1}{\sqrt{3}} + (2 + \sqrt{3})}{1 - \frac{1}{\sqrt{3}}(2 + \sqrt{3})} \]
\[ a_4 = \frac{\frac{1 + \sqrt{3} + 2\sqrt{3} + 3}{\sqrt{3}}}{1 - \frac{2 + \sqrt{3}}{\sqrt{3}}} = \frac{\frac{4 + 3\sqrt{3}}{\sqrt{3}}}{1 - \frac{2\sqrt{3} + 3}{3}} = \frac{\frac{4 + 3\sqrt{3}}{\sqrt{3}}}{\frac{3 - 2\sqrt{3} - 3}{3}} = \frac{\frac{4 + 3\sqrt{3}}{\sqrt{3}}}{\frac{-2\sqrt{3}}{3}} \]
\[ a_4 = \frac{4 + 3\sqrt{3}}{\sqrt{3}} \cdot \frac{3}{-2\sqrt{3}} = \frac{3(4 + 3\sqrt{3})}{-2 \cdot 3} = \frac{4 + 3\sqrt{3}}{-2} = -2 - \sqrt{3} \]

### Step 3: Compute \( a_5 \)
