Question: The terms of the sequence \$(a_i)\$ defined by \$a_{n + 2} = \frac {a_n + 2009} {1 + a_{n + 1}}\$ for \$n \ge 1\$ are positive integers. Find the minimum possible value of \$a_1 + a_2\$.

Solution chain-of-thought reasoning: This question is guessable but let's prove our answer
a_{n + 2} = \frac {a_n + 2009} {1 + a_{n + 1}}
a_{n + 2}(1 + a_{n + 1})= a_n + 2009
a_{n + 2}+a_{n + 2} a_{n + 1}-a_n= 2009
lets put \$n+1\$ into \$n\$ now
a_{n + 3}+a_{n + 3} a_{n + 2}-a_{n+1}= 2009
and set them equal now
a_{n + 3}+a_{n + 3} a_{n + 2}-a_{n+1}= a_{n + 2}+a_{n + 2} a_{n + 1}-a_n
a_{n + 3}-a_{n+1}+a_{n + 3} a_{n + 2}-a_{n + 2} a_{n + 1}= a_{n + 2}-a_n
let's rewrite it
(a_{n + 3}-a_{n+1})(a_{n + 2}+1)= a_{n + 2}-a_n
Let's make it look nice and let \$b_n=a_{n + 2}-a_n\$
(b_{n+1})(a_{n + 2}+1)= b_n
Since \$b_n\$ and \$b_{n+1}\$ are integers, we can see \$b_n\$ is divisible by \$b_{n+1}\$
But we can't have an infinite sequence of proper factors, unless \$b_n=0\$
Thus, \$a_{n + 2}-a_n=0\$
a_{n + 2}=a_n
So now, we know \$a_3=a_1\$
a_{3} = \frac {a_1 + 2009} {1 + a_{2}}
a_{1} = \frac {a_1 + 2009} {1 + a_{2}}
a_{1}+a_{1}a_{2} = a_1 + 2009
a_{1}a_{2} = 2009
To minimize \$a_{1}+a_{2}\$, we need \$41\$ and \$49\$
Thus, our answer \$= 41+49=\boxed {090}\$

Solution steps:
--------------------------------------------------
Step 0: Define the recurrence relation for the sequence as \( a_{n + 2} = \frac{a_n + 2009}{1 + a_{n + 1}} \).

Step 1: Rearranging the relation gives \( a_{n + 2}(1 + a_{n + 1}) = a_n + 2009 \).

Step 2: Substitute \( n + 1 \) into the original relation to get \( a_{n + 3}(1 + a_{n + 2}) = a_{n + 1} + 2009 \).

Step 3: Set the two equations from steps 1 and 2 equal to each other: \( a_{n + 3} + a_{n + 3} a_{n + 2} - a_{n + 1} = a_{n + 2} + a_{n + 2} a_{n + 1} - a_n \).

Step 4: Rearrange the equation from step 3 to isolate terms: \( (a_{n + 3} - a_{n + 1})(a_{n + 2} + 1) = a_{n + 2} - a_n \).

Step 5: Let \( b_n = a_{n + 2} - a_n \) to simplify the equation: \( (b_{n + 1})(a_{n + 2} + 1) = b_n \).

Step 6: Since \( b_n \) and \( b_{n + 1} \) are integers, \( b_n \) must be divisible by \( b_{n + 1} \). 

Step 7: Conclude that if \( b_n \) is an infinite sequence of proper factors, it must equal zero, implying \( a_{n + 2} - a_n = 0 \), hence \( a_{n + 2} = a_n \).

Step 8: Since \( a_3 = a_1 \), substitute back into the relation: \( a_1 = \frac{a_1 + 2009}{1 + a_2} \).

Step 9: Rearranging gives \( a_1 + a_1 a_2 = a_1 + 2009 \), leading to \( a_1 a_2 = 2009 \).

Step 10: To minimize \( a_1 + a_2 \), find the factor pairs of 2009, which are \( (1, 2009), (7, 287), (41, 49) \).

Step 11: Calculate the sums for each factor pair: \( 1 + 2009 = 2010 \), \( 7 + 287 = 294 \), and \( 41 + 49 = 90 \).

Step 12: Identify the minimum value as \( 90 \).

Final answer: \(\boxed{90}\)
