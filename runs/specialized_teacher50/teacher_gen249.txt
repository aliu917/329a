Step 1: Since \$\frac{x}{y}\$ is an integer, it implies that \$y | x\$ (y divides x).
Step 2: Since \$\frac{x+1}{y+1}\$ is also an integer, it implies that \$y + 1 | x + 1\$ (y + 1 divides x + 1).
Step 3: By the properties of gcd, we have \$\text{gcd}(y, x) = y\$ and \$\text{gcd}(y + 1, x + 1) = y + 1\$.
Step 4: These gcd conditions can be rewritten as \$\text{gcd}(y, x - y) = y\$ and \$\text{gcd}(y + 1, x - y) = y + 1\$.
Step 5: The implications of the gcd conditions indicate that both \$y\$ and \$y + 1\$ must divide \$x - y\$.
Step 6: Since \$\text{gcd}(y, y + 1) = 1\$, it follows that \$y(y + 1) | x - y\$.
Step 7: For a given value of \$y\$, we need to find the number of multiples of \$y(y + 1)\$ from \$0\$ to \$100 - y\$ (since \$x \leq 100\$).
Step 8: The number of satisfactory positive integers for each \$y\$ can be expressed as \$\left\lfloor \frac{100 - y}{y(y + 1)} \right\rfloor\$.
Step 9: Sum this count for all integers \$y\$ from \$1\$ to \$99\$ to find the total number of ordered pairs \$(x, y)\$.
Step 10: Calculate the sum: 
\[
