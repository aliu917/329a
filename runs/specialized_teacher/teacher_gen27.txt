(a-d)^2 + a^2 + (a+d)^2 = a \cdot d^2
\]

First, we expand the left side of the equation:

\[
(a-d)^2 + a^2 + (a+d)^2 = (a^2 - 2ad + d^2) + a^2 + (a^2 + 2ad + d^2) = 3a^2 + 2d^2
\]

So the equation becomes:

\[
3a^2 + 2d^2 = ad^2
\]

Rearranging terms, we get:

\[
3a^2 + 2d^2 - ad^2 = 0
\]

Factoring out \(d^2\) from the right side, we obtain:

\[
3a^2 + d^2(2 - a) = 0
\]

This can be rewritten as:

\[
3a^2 = d^2(a - 2)
\]

For \(d^2(a - 2)\) to be a positive integer, \(a - 2\) must be a positive divisor of \(3a^2\). We will test positive integer values for \(a\) starting from 3:

1. If \(a = 3\):
   \[

   \]
2. If \(a = 4\):
   \[
   3(4)^2 = d^2(4 - 2) \implies 48 = 2d^2 \implies d^2 = 24 \quad (\text{not a perfect square})
   \]
3. If \(a = 5\):
   \[
   3(5)^2 = d^2(5 - 2) \implies 75 = 3d^2 \implies d^2 = 25 \implies d = \pm 5
   \]
   The terms of the sequence are \(0, 5, 10\) or \(10, 5, 0\) (but since the sequence is strictly increasing, we take \(0, 5, 10\)). The third term is 10.
4. If \(a = 6\):
   \[

   \[
