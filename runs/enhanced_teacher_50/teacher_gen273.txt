Question: For some integer \$m\$, the polynomial \$x^3 - 2011x + m\$ has the three integer roots \$a\$, \$b\$, and \$c\$.  Find \$|a| + |b| + |c|\$.

Solution chain-of-thought reasoning: From Vieta's formulas, we know that \$a+b+c = 0\$, and \$ab+bc+ac = -2011\$. Thus \$a = -(b+c)\$. All three of \$a\$, \$b\$, and \$c\$ are non-zero: say, if \$a=0\$, then \$b=-c=\pm\sqrt{2011}\$ (which is not an integer). \$\textsc{wlog}\$, let \$|a| \ge |b| \ge |c|\$. If \$a > 0\$, then \$b,c < 0\$ and if \$a < 0\$, then \$b,c > 0\$. We have -2011=ab+bc+ac = a(b+c)+bc = -a^2+bc
Thus \$a^2 = 2011 + bc\$. We know that \$b\$, \$c\$ have the same sign. So \$|a| \ge 45 = \lceil \sqrt{2011} \rceil\$.

Solution steps:
--------------------------------------------------
Step 0: Denote the integer roots of the polynomial as \$a\$, \$b\$, and \$c\$. From Vieta's formulas, we establish that \$a + b + c = 0\$ and \$ab + ac + bc = -2011\$.

Step 1: Since \$a + b + c = 0\$, we can express \$a\$ in terms of \$b\$ and \$c\$: \$a = -(b + c)\$.

Step 2: We substitute \$a\$ into the equation \$ab + ac + bc = -2011\$ to get \$-(b + c)b - (b + c)c + bc = -2011\$.

Step 3: Simplifying gives us: \$-b^2 - bc - c^2 + bc = -2011\$, which simplifies to \$-b^2 - c^2 = -2011\$, or \$b^2 + c^2 = 2011\$.

Step 4: All three roots \$a\$, \$b\$, and \$c\$ are non-zero integers. We assume without loss of generality that \$|a| \ge |b| \ge |c|\$.

Step 5: Since \$b + c = -a\$, if \$a > 0\$, then \$b, c < 0\$; if \$a < 0\$, then \$b, c > 0\$.

Step 6: From the equation \$b^2 + c^2 = 2011\$, we derive that \$|a| = |b + c|\$ and since \$a^2 = b^2 + c^2 + 2bc = 2011 + 2bc\$, we can express \$bc\$ in relation to \$a\$.

Step 7: We also note that for maximization of the product \$bc\$, \$b\$ and \$c\$ should be close to each other, which leads us to consider the distribution of \$2011\$ among \$b\$ and \$c\$.

Step 8: We calculate the possible values for \$a\$ by testing integer values from \$45\$ to \$51\$ based on the derived inequalities.

Step 9: We construct a table of values for \$|a|\$, calculating \$bc = a^2 - 2011\$ for each \$|a|\$.

Step 10: We find that at \$|a| = 46\$, \$bc = 105\$, which does not yield valid integer pairs. We continue testing other values.

Step 11: At \$|a| = 49\$, we find that \$bc = 390\$, which can yield integer solutions.

Step 12: We solve for \$b\$ and \$c\$ using the quadratic formed from \$x^2 - (b+c)x + bc = 0\$.

Step 13: We find integers \$b = 39\$ and \$c = 10\$, verifying that they satisfy all original equations.

Step 14: Finally, we compute \$|a| + |b| + |c| = 49 + 39 + 10\$.
